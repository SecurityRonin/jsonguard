# Privacy Policy

*Last updated: 2026-07-24*

## Summary

jsonguard is a local Rust library. It does not collect, transmit, or store any personal data on remote servers.

## Data Access

jsonguard inspects and sanitizes only the input you pass to it. All processing happens in memory on your local machine. Nothing is uploaded anywhere.

## Telemetry

jsonguard has **no telemetry**. It makes no network requests of any kind.

## Open Source

jsonguard is open source (Apache-2.0). You can audit every line of code at [github.com/SecurityRonin/jsonguard](https://github.com/SecurityRonin/jsonguard).
